## 各項討論

### 1. 實驗方式

會中提出的方法：

1. **跑 N 次，看成功幾次**：A 組政府沒有記憶，成功與否幾乎是隨機的，只看運氣。
2. **看經歷到第幾次天災才成功**：C 組政府有記憶，若第一次就成功，之後可能每次都成功，後面的實驗就沒有意義。
3. **新增：設定期限**：天災發生後給固定天數（例如 10 天，數字只是舉例），期限內沒回到均衡價格就算失敗。可以多測幾次再取平均。

**結論**：這些問題的前提是「還不知道 Agent 會不會做出很出格的事，或其實很聰明一看就會」。等系統做出來後實際測試再決定，這部分也可以成為期末報告的內容。

### 2. B 組社會規則何時定案

- 問題：B 組要跑幾次、看到什麼程度，才算社會規則足夠？
- 社會規則之後很難隨時修改，所以要在跑 A、C 組之前定好。
- 規則某種程度上就是「記憶」：發生一件事後，政府知道這件事不能做，然後寫進記憶。

**結論**：先跑 B 組觀察，看結果覺得規則夠了就定案。

### 3. 成功標準與怎樣算恢復

- 討論的情境：天災後政府在第 2 天就回到均衡價格，但之後市場又崩掉，第 10 天時不在均衡價格，這樣算成功還是失敗？
- 另一個情境：政府直接把價格硬性調到均衡價格，算不算成功？（未討論出結論）

**結論**：

- 均衡價格是一個**區間**，不是單一數字。
- 區間用穩定期的數值計算：穩定期跑出多個均衡價格，取平均 ± 2～3 個標準差。
- 評估期內價格必須**一直維持**在區間內直到評估期結束，中途跑出區間就不算成功（README 的選項 2）。

### 4. 均衡狀態標準

**每次重置要回到什麼狀態**

- 除了記憶之外，所有狀態都回到一開始的設定（初始世界），這樣有記憶與沒記憶的組別才有可比性。
- **人口要補回**：在 B 組，人口是基準值之一，所以要固定。
  - 補充：上週提過「就算把人全殺光，只要價格回到均衡也算成功」。這和人口要固定的做法要再對齊。
- 評估期結束時直接強制把社會調回均衡狀態，再跑下一次天災。

**天災**

- 每次天災的數字是否相同？討論到「嚴重程度隨機、頻率固定」，但 README 目前寫的是各組使用相同強度。**待確認**。
- 不考慮恢復期間又發生天災的情況（太複雜），只看單次天災後的恢復能力。

**研究重點**

- 這次的重點是**記憶會不會影響結果**，主要比較 A 組與 C 組。B 組只是過程，用來訂社會規則。

**均衡價格怎麼算（待討論）**

- 不是現實世界的均衡價格，而是模擬中四種平民（有無買賣 × 有無產出）交易後的供需均衡價格。
- 有人提出「總糧食量 ÷ 每人願意付的錢」之類的算法，但沒有定論。
- 有一版自訂公式：以變動最多的價格作為均衡（需再確認）。
- 負責：社會規則負責人。會中提到可以先請 Claude 協助推導有依據的公式。

**飢餓與死亡機制（待確認）**

- 方案 A：每個平民有初始飢餓值，每天扣一定數值，幾天沒吃東西就死亡。
- 方案 B：不設飢餓值，規則改成「產量低於某個值就要買進糧食」。不會有人餓死，也不需要考慮搶糧，比較簡單。
- 傾向：第一版先不做飢餓值，系統做出來後再加入更多機制。最優先的是先確定**均衡價格怎麼算**，因為它是主要的產出。

### 5. B 組的「亂搞」怎麼記錄

- B 組沒有社會規則，怎麼做都不會違規，所以要由我們判斷什麼算亂搞。
- 兩種判斷方式要分開記錄：
  - **行為種類**：只要做了就算亂搞。
  - **行為程度**：可以做，但超過某個門檻就算亂搞（例如發行貨幣超過多少）。
- B 組要有記憶、沒有社會規則。

**結論**：先讓 B 組跑出一批決策，由人工判斷哪些不行，再訂成規則。這部分由子凌在分工表中負責。

### 6. 政府平時可不可以決策 & 天災預報

**平時決策**

- 可以：政府能未雨綢繆（例如穩定期先囤糧、多種作物、提前收割），能顯示有記憶與沒記憶的差別。
- 不可以：能確保每次社會穩定時的狀態完全一樣。
- 選擇取決於研究目標：如果是看政府能不能從過去經驗中學習，提前準備也是一種學習。
- 有人認為不開放比較簡單；也有人認為這只是多一條「平時也可以決策」的規則，不會比較複雜。
- **傾向開放**，但沒有正式表決，**待確認**。

**天災預報**

- **結論：不提供預報**。如果有預報又能提前決策，政府一定會先囤糧，和沒預報的差距會太大，影響數據。
- 政府要憑記憶中過去的經驗判斷。
- 目前平民也沒有階級或資訊落差，一律平等（上次「富農提前收到天災資訊」的設定不沿用）。

> ⚠️ README 的實驗流程目前有「天災預報」這一步，固定條件也提到預警時間，需要配合修改。

### 7. 「一天」的定義

- 所有考量因素都跑過一遍算一天，也就是一回合。
- 平民每天只能依身分選一個動作（例如交易或收割）。
- 政府每天可以決定要不要改變規則。
- 由社會規則負責人定義清楚。

### 8. 政府看得到什麼

| 資訊 | 是否可見 |
|---|---|
| 當下價格 | ✅ |
| 自己的預算與儲備 | ✅ |
| 死亡人數 | ✅ |
| 挨餓人數 | ✅（如果有飢餓機制） |
| 平民的庫存 | ❌ 現實中政府不會知道 |

相關想法：

- 「有產出、沒交易」的平民會自己囤糧。政府發現糧食不夠時，可以強制讓他們交易，這屬於政府的決策。
- 政府發糧食也可以做成一種政策。

### 9. 「遵守政府政策」的具體行為

- 逐一定義每種行動的不遵守行為太複雜，平民是 rule-based，沒有自己的判斷。
- 做法：在 persona 設定不服從比例（例如 30% 不服從），寫好不服從時會怎麼做即可。
- 未解決：政府取得糧食的方式是**強制徵收**還是**購買**？徵收要不要付錢？兩者對均衡價格的影響不同，等實作後再看哪些因素會影響。
